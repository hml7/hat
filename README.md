# hat
A recreational programming project that reeimplements <i>cat(1)</i> in Hare. Heavily inspired by [sharkdp's bat](https://github.com/sharkdp/bat).

> [!CAUTION]
> As hat is developed completly as a recreational programming project it does not aim to be a full cat replacement but rather it's own unique approach.

I would highly advise you to check out `hat` as something that aims to bring you prettier `cat` experience and not as a drop-in replacement for it as it is still developed.

> [!NOTE]
> Despite above-mentioned things hat aims to one-day be a drop-in replacement for (POSIX) `cat` just like `bat`.
